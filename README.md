# BukuKita – Website Toko Buku

## 1. Deskripsi Project

BukuKita merupakan aplikasi website toko buku sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

Website ini dirancang untuk menampilkan informasi buku, seperti judul, kategori, harga, stok, dan gambar sampul buku. Website juga menyediakan beberapa fitur untuk membantu pengguna mengakses informasi dan melakukan pengelolaan data buku.

## 2. Tujuan Project

Tujuan pembuatan website BukuKita adalah:
- Menerapkan penggunaan HTML untuk membuat struktur website.
- Menggunakan CSS untuk mengatur desain dan tampilan.
- Menggunakan JavaScript untuk menambahkan fungsi dan interaksi.
- Memahami proses pembuatan website dari tahap perancangan hingga pengujian.

## 3. Teknologi yang Digunakan

- **HTML** – Membuat struktur halaman website.
- **CSS** – Mengatur warna, tata letak, dan tampilan website.
- **JavaScript** – Mengatur fungsi dan interaksi website.
- **LocalStorage** – Menyimpan data tertentu pada browser.

## 4. Fitur Website

Beberapa fitur yang terdapat pada website BukuKita:
- Halaman login dan pendaftaran akun.
- Halaman dashboard.
- Katalog buku.
- Pencarian dan penyaringan kategori buku.
- Pengelolaan data dan stok buku.
- Keranjang dan pemesanan buku.
- Pelacakan pesanan.

## 6. Proses Pembuatan Website

### A. Tahap Perancangan
Menentukan konsep website toko buku, fitur yang dibutuhkan, dan struktur halaman.

### B. Pembuatan Struktur HTML
Membuat struktur halaman, navigasi, form, tombol, dan bagian konten menggunakan HTML.

### C. Pembuatan Tampilan CSS
Mengatur warna, ukuran tulisan, tata letak, tombol, dan tampilan katalog buku menggunakan CSS.

### D. Pembuatan Fungsi JavaScript
Menambahkan fungsi untuk login, menampilkan katalog, pencarian buku, pengelolaan stok, dan pemesanan.

### E. Pengujian Website
Menjalankan website melalui browser dan mencoba fitur yang tersedia untuk memastikan fungsi website berjalan dengan baik.
